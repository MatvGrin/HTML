CSS Tabs

radio inputs, labels, panels, stateful CSS without JavaScript. This page is built as a practical mini project, not as a tiny isolated snippet, so you can open it in the browser and play with the layout.

Theory in simple words

Tabs show one group of content at a time. This CSS-only version uses radio buttons as state holders and labels as tab buttons. It is a good exercise in selectors and sibling relationships.

How to study this file: first look at the HTML comments to understand the meaning of the tags. Then open style.css and change spacing, colors, grid sizes, or states. Small changes are the fastest way to learn CSS.
