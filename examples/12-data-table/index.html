Data Table

table semantics, sticky header, zebra rows, responsive overflow. This page is built as a practical mini project, not as a tiny isolated snippet, so you can open it in the browser and play with the layout.

Theory in simple words

Tables are still the correct HTML for tabular data. CSS should improve scanning with alignment, row states, sticky headers, and responsive overflow. Avoid replacing real tables with divs when the content is truly data.

How to study this file: first look at the HTML comments to understand the meaning of the tags. Then open style.css and change spacing, colors, grid sizes, or states. Small changes are the fastest way to learn CSS.

What to try

Scroll horizontally on a small screen; the table remains usable instead of breaking the page.
