CSS custom properties, theme tokens, local overrides. This page is built as a practical mini project, not as a tiny isolated snippet, so you can open it in the browser and play with the layout.

Theory in simple words

CSS custom properties work like design tokens. You define colors, spacing, radius, and shadows once, then reuse them. Local overrides make themes easy without rewriting every selector.

How to study this file: first look at the HTML comments to understand the meaning of the tags. Then open style.css and change spacing, colors, grid sizes, or states. Small changes are the fastest way to learn CSS.
